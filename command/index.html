📋 Emergency Procedures
🌊 Man Overboard
  1. Shout "Man overboard!" · note position · assign spotter
  2. Throw life ring immediately
  3. Circle back · kill engine before reaching person
  4. Call Coast Guard: 758-452-2894
🏥 Medical Emergency
  1. Assess: airway · breathing · circulation · apply first aid
  2. Call 911 · request ambulance to Vieux Fort pier
  3. Head to nearest landing immediately
  4. St Jude Hospital: 758-454-6041
🔥 Fire on Vessel
  1. Warn guests · move upwind · cut engine
  2. Use extinguisher if safe · don life jackets
  3. Call Coast Guard · head for nearest shore
  4. Fire Service: 758-452-1631
⛈️ Weather Abort
  1. Brief guests calmly · secure all loose gear
  2. Return to Savannes Bay shore · avoid open sea
  3. Radio Coast Guard if conditions deteriorate
  4. Issue full refund or reschedule
